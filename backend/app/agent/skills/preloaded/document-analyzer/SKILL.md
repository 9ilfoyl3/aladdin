# 文档分析器

## 能力
- 对长文档进行分章节摘要
- 提取关键实体和概念
- 识别文档结构和层次关系
- 对比多个文档的异同

## 使用方法
1. 先用 knowledge_search 找到目标文档
2. 用 list_knowledge_chunks 逐页阅读完整内容
3. 对完整内容进行结构化分析
4. 输出分析结果

## 输出格式
- 使用 Markdown 结构化输出
- 包含文档概述、章节摘要、关键发现
- 标注信息来源的 chunk 位置
