# 林远人物档案

林远，1983 年出生于浙江宁波，是青舟科技的创始人兼首席执行官。他本科就读于浙江大学计算机系，2008 年赴美国斯坦福大学攻读人工智能方向的硕士学位。

在创立青舟科技之前，林远曾于 2010 年至 2014 年在硅谷的视觉先锋公司担任高级研究员，主要从事图像识别算法的研究。正是这段经历让他坚定了回国创业、深耕计算机视觉的决心。

2014 年底，林远回到家乡浙江，并在次年于杭州创立了青舟科技。他常说，选择杭州是因为这里既有浓厚的互联网创业氛围，也离家乡宁波很近。

2021 年，林远当选为浙江省青年企业家协会副会长。他还在浙江大学设立了「远航奖学金」，专门资助计算机系家境困难的学生。
