# 北斗物流项目纪要

「北斗物流」是青舟科技于 2022 年启动的智慧物流项目，由青舟科技与云栖智能联合发起，目标是把计算机视觉技术应用到智慧仓储与自动分拣中。

项目落地在江苏苏州的一座大型物流仓库，仓库由云栖智能负责运营。青舟科技提供的视觉算法源自灵眸相机产品线，经过改造后用于货品的自动识别与分拣。

项目的技术总负责人是青舟科技首席技术官苏晴，她带领算法团队驻场苏州数月，与云栖智能的工程师一起调试分拣精度。项目上线后，仓库的分拣错误率下降了百分之四十以上。

北斗物流是青舟科技第一次进入物流行业，也被林远视为公司业务多元化的重要一步。项目的成功让青舟科技在 2023 年获得了更多来自物流企业的合作意向。
