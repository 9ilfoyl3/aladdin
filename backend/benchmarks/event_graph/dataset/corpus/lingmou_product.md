# 灵眸相机产品演进

灵眸相机是青舟科技的旗舰产品线，定位于工业质检领域的智能视觉设备。第一代灵眸相机于 2017 年正式发布，主打表面缺陷检测，广泛应用于 3C 电子制造的产线。

第一代产品的核心缺陷检测算法由苏晴主导研发，凭借高召回率在电子代工厂中口碑良好。2017 年发布当年，灵眸相机就拿下了来自珠三角多家代工厂的订单。

2019 年，青舟科技发布第二代灵眸相机，新增了对金属件和玻璃件的检测能力，并把推理速度提升了近三倍。第二代产品开始进入汽车零部件质检市场。

2022 年，灵眸相机的视觉算法被移植到「北斗物流」项目中，用于仓储货品的自动识别与分拣。这标志着灵眸的技术能力从工业质检扩展到了物流分拣场景。
