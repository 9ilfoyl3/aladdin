# AGENTS.md — Agent Notes

Agent Notes are durable decision records. They preserve rationale, alternatives, consequences, and required verification for changes that code alone cannot explain.

Follow [README.md](README.md) for the complete lifecycle, classification, naming, and format rules. Every non-trivial Artoo change must add or update the owning note in the same PR. Search the active tree before creating a note; update the existing owner instead of creating a duplicate.

Files under `archived/` are frozen historical snapshots. Never edit them or treat them as current authority.
